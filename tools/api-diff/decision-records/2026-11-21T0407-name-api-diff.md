# Name the tool api-diff

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-11-21 04:07 UTC |
| **Summary** | Keep `api-diff` as the tool's name. |
| **Milestone** | M0 |

## Background

The name sets the command, config file, extension and release tag names.

## Alternatives considered

- **openapi-compat**: Emphasises compatibility.
- **spec-delta**: Less likely to clash.

## Decision

`api-diff`: command `api-diff`, policy `api-diff.yaml`, acknowledgements `api-diff.ack.yaml`, extension `x-api-diff`, release tags `api-diff-v<version>`.

## Impacts

- The npm name isn't needed while we distribute release files only.
