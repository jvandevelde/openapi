# Support OpenAPI 3.0, 3.1 and 3.2

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-11-21 04:07 UTC |
| **Summary** | Support OpenAPI 3.0, 3.1 and 3.2 from the start through a normalise step. |
| **Milestone** | M2 |

## Background

Teams have specs in all three versions, and comparing across versions must not report cosmetic differences.

## Alternatives considered

- **3.0 and 3.1 only**: 3.2 added later.
- **3.1 and 3.2 only**: Drops 3.0 specs.

## Decision

All three versions normalise into one internal dialect (e.g. `nullable: true` → `type: [.., "null"]`, boolean `exclusiveMinimum` → numeric). Swagger 2.0 is out of scope.

## Impacts

- 3.2 operations such as `query` and `additionalOperations` are modelled.
